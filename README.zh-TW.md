# The Past Is Yet to Come（白露未晞）

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

你經營一家時空派遣事務所。派員工前往歷史的轉折點，選好人和裝備，等他們回來講述這趟發生了什麼。員工只能影響旅程產生的歷史分支，報告會把結果與沒有員工介入時的模擬對照。

## 遊玩

[在瀏覽器遊玩](https://www.pastyet.com/?lang=zh-Hant)。在 Windows 上，也可以安裝 Python 3 後執行儲存庫中的 `run_game.cmd`，再開啟[本機遊戲](http://127.0.0.1:8778/index.html?lang=zh-Hant)。
