# The Past Is Yet to Come（白露未晞）

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

시간 여행 파견 회사를 운영하는 브라우저 게임입니다. 직원과 장비를 골라 역사의 전환점으로 보내고, 돌아온 직원의 보고서를 읽습니다. 보고서에서는 직원이 개입한 결과를 개입하지 않았을 때의 시뮬레이션과 비교할 수 있습니다.

## 플레이

[브라우저에서 플레이](https://www.pastyet.com/?lang=ko). Windows에서는 Python 3을 설치하고 저장소의 run_game.cmd를 실행한 뒤 [로컬 게임](http://127.0.0.1:8778/index.html?lang=ko)을 열 수 있습니다.
