# The Past Is Yet to Come（白露未晞）

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

時間旅行の派遣会社を運営するブラウザーゲームです。スタッフと装備を選び、歴史の転換点へ送り出します。帰還後の報告書では、旅が生んだ歴史の分岐と、スタッフが介入しなかった場合のシミュレーションを比べられます。

## 遊び方

[ブラウザーで遊ぶ](https://www.pastyet.com/?lang=ja)。Windows では Python 3 を用意し、リポジトリ内の `run_game.cmd` を実行してから、[ローカル版](http://127.0.0.1:8778/index.html?lang=ja)を開くこともできます。
