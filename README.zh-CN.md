# The Past Is Yet to Come（白露未晞）

[English](README.md) · [简体中文](README.zh-CN.md) · [繁體中文](README.zh-TW.md) · [日本語](README.ja.md) · [한국어](README.ko.md)

你经营一家时空派遣事务所。派员工前往历史的转折点，选好人和装备，等他们回来讲述这一趟发生了什么。员工只能影响旅程产生的历史分支，报告会把结果与没有员工介入时的模拟对照。

## 游玩

[在浏览器游玩](https://www.pastyet.com/?lang=zh)。在 Windows 上，也可以安装 Python 3 后运行仓库中的 `run_game.cmd`，再打开 [本地游戏](http://127.0.0.1:8778/index.html?lang=zh)。
